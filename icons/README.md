# AVA PWA icons

The root PWA manifest and Apple touch icon metadata reserve these paths for
the approved AVA logo exports, which are uploaded separately through GitHub:

- `ava-192.png` — 192 × 192 standard PWA and Apple touch icon
- `ava-512.png` — 512 × 512 high-resolution PWA icon
- `ava-maskable-512.png` — 512 × 512 Android maskable icon with a suitable safe zone
