# AVA PWA icons

No placeholder artwork is stored here. Add the approved AVA logo exports in a
separate change, then add their entries to `manifest.webmanifest` and the Apple
touch icon link to `index.html`:

- `ava-192.png` — 192 × 192 standard PWA and Apple touch icon
- `ava-512.png` — 512 × 512 high-resolution PWA icon
- `ava-maskable-512.png` — 512 × 512 Android maskable icon with a suitable safe zone
